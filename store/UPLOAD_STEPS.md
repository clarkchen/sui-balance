# Chrome Web Store 上架与更新

当前产品已发布。更新商店展示文案时，在开发者后台打开 Sui Balance 的「商品详情」。

1. 英文「详细说明」只粘贴 `LISTING_EN.md` 的全文。添加简体中文本地化时，只粘贴 `LISTING.md` 的全文。这两个文件没有内部填写说明或 Markdown 标记。
2. 英文首页网址填写 `https://sui-balance.0xclark.dev/`；中文可填写 `https://sui-balance.0xclark.dev/zh/`。
3. 「隐私权」中的隐私政策网址填写 `https://sui-balance.0xclark.dev/privacy/`。中文政策页面位于 `/zh/privacy/`。
4. 权限用途、单一用途及数据处理说明见 `REVIEW_EN.md` 或 `REVIEW_ZH.md`。不要把审核字段文件粘贴到公开详细说明。
5. 保存草稿并按商店提示提交更新。公开页面生效可能需要审核。

扩展程序包更新时，需另行上传新版本 ZIP；单纯修改商店文案或网址不需要更改扩展程序包。
